## 📁 Projects

### 1. Rossmann Store Sales Prediction

A retail sales forecasting project that predicts daily sales using historical sales data, promotions, store information, and time-based features.

**Key Features**

* Data preprocessing and exploratory data analysis
* Calendar, promotion, and competition feature engineering
* Lag and rolling-window sales features
* Random Forest regression
* Recursive time-series validation
* Sales prediction generation

**Validation Results**

* MAE: 725.94
* RMSE: 1,130.36

*These results are from chronological recursive validation.*

**Technologies:** Python, Pandas, NumPy, Scikit-learn
